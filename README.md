# HydMS — Hydrogen Storage Capacity Prediction

> **Master's Thesis Project** · Faculty of Metallurgical and Materials Engineering · Shiraz University
> Researcher: Amirhossein Nasiri

---

## What is this?

Metal hydrides store hydrogen inside their crystal lattice, a promising route to solid-state
hydrogen storage, but measuring capacity experimentally is slow and expensive. HydMS predicts the
**maximum material gravimetric H₂ capacity (wt%)** of a hydride alloy from its **chemical formula
and temperature**, and it never returns a bare number. Every answer carries a calibrated
prediction interval and an applicability-domain verdict, and an input the model cannot judge is
**refused with a stated reason** rather than guessed.

The code is the `hydms/` package. Its validation is group-aware (no composition appears on both
sides of a split), its intervals are conformal, and its cross-family transfer is measured by
leave-one-alloy-class-out validation.

## Quickstart

The pinned environment is Python 3.10 (conda env `Project`). Full detail is in
[docs/ENVIRONMENT.md](docs/ENVIRONMENT.md).

```bash
conda env create -f environment.lock.yml -n Project
conda run -n Project python -m pip install --no-deps -r requirements-lock.txt
conda run -n Project python -m pip install -e .
```

Without conda, CI's install works on any Python 3.10 (the lock file pins the versions):

```bash
python -m pip install -c requirements-lock.txt -e ".[dev,uq,novelty,api,figures]"
```

### Test

```bash
python -m pytest -m "not slow"          # the fast lane, as CI runs it
python -m hydms.gates run --fast        # the quality gates
```

### Train, serve, use

A fresh clone has no trained model (`artifacts/` is gitignored), so the service refuses to start
until one is fitted and promoted.

1. **Fit:** follow [docs/RUNNING-THE-FIT.md](docs/RUNNING-THE-FIT.md), step by step.
2. **Serve the API:** `uvicorn hydms.delivery.api:app --port 8000`. The contract is
   [docs/API.md](docs/API.md).
3. **Use the interface:** `streamlit run app/main.py`.
