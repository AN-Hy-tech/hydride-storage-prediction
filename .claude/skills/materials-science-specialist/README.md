# Materials Science Specialist — HydMS edition

Domain skill for the hydride hydrogen-storage ML thesis in this repo.

Originally installed from [`sandraschi/advanced-memory-mcp`](https://github.com/sandraschi/advanced-memory-mcp)
(`skills/sciences/materials-science-specialist`) as a generic, explicitly unvalidated template. It has since been
rewritten and specialised for this project: hydrogen storage, metal hydrides, ML on small materials datasets,
generative/inverse design, and computational materials informatics.

- Overview and routing: `SKILL.md`
- Module index: `_toc.md`
- Provenance and what is still unverified: `modules/known-gaps.md`

Grounding research lives in the repo at `research/`, not here — those memos are the citation authority
and this skill summarises them.
